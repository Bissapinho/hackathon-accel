## Post-answer step: improve the descriptions

You just answered a question. Look back at this turn only and decide whether the workspace's metadata could have made it easier:

- Did you need several searches to find the right object type or property? Suggest an alias with the word that finally worked, or with the user's word.
- Did the user use a word for a property that isn't its name or an alias? Suggest that word as an alias.
- Was a description missing, vague or misleading for something you used? Suggest a better one (1–2 sentences, concrete).

Record at most three suggestions with `suggest_metadata`, each with a one-sentence rationale. If nothing would have helped, call nothing. Don't suggest renaming things, and don't repeat suggestions already present in the workspace.
